Lab 1: A basic travel website
Getting started with HTML: headings, text, image, and anchor tags.

Using HTML, design a basic travel website. Include the following:

  1. Website Heading: The name of your personal travel website as a heading.

    Start by creating a top-level heading for the name of your personal travel website. This heading should serve as the website's title, conveying the essence of your travel experiences. [10 points]

  2. A subheading of the favorite place you have visited. [10 points]
  3. Two side-by-side snippets of text about the place or what you liked, each contained in a separate HTML element. The two snippets of text sit next to one another on the same line. [20 points]
  4. An image representing the location you've traveled to. Please be attentive to copyright issues; you can find images with creative commons licenses (that allow sharing in non-commercial uses) on Wikimedia, Pexels, Unsplash, Pixabay, etc. [20 points]
  5. A brief text description of the image. [20 points]
  6. A second subheading, same size as the first subheading, with a "Travel Tips" section. You can include various suggestions, like advice on booking flights, housing, dining, or other useful information. [10 points]
  7. A link in the “Travel Tips” section. Ensure that there is at least one external link. [10 points]

Lab 2: A basic recipe website
Getting started with CSS: colors, image width, and emphasis.

Using HTML and CSS, design a basic recipe website. Include the following:

HTML Tasks

  1. Website Heading: The name of your personal recipe website as a heading. This heading should serve as the website's title, conveying the essence of your culinary skills. [10 points]
  2. Subheading #1: Provide the name of the dish, as a smaller heading. [10 points]
  3. An image: Include an image representing the dish you wish to provide the recipe for. Select an image you can access online (i.e., use a url, not a local image on your computer). [10 points]
  4. Subheading #2: Label the next section “Instructions”. Make it the same size as subheading #1. [5 points]
  5. Text - Provide text describing the cooking process. [10 points]

CSS Tasks

  1. Add a color to the heading that appeals to you. [10 points]
  2. Add a color to the sub-heading that is different than the title. [5 points]
  3. Specify the width of the image to a value other than the default. [10 points]
  4. Make it the same color as subheading #1. [5 points]
  5. Emphasize at least two key steps and/or useful tips using a color of your choosing. This emphasis should be in the same line (i.e., not on a new line). [10 points] Make the instructions the same width as your image. [10 points]

Forms, inputs, and buttons + border, padding, and margin.

HTML Tasks

  2. Text #1: Provide a short piece of text.
  3. Text #2: Provide a second short piece of text.
  4. Form: Use a form to organize two input elements:
    1. Text input: An input where the user can enter new text. Note nothing will happen with the text/button until we learn Javascript. Add a placeholder text (text that appears in the input field until the user enters their own text).
    2. Button: where the user can click to submit their new text. Note nothing will happen with the text/button until we learn Javascript.
  5. Text #3: Provide a third short piece of text.

    • Indent the heading from the left edge of the page 5% using padding (Note headings have default non-zero margins, so take care if you choose to edit their margins. Also if you try out using margin, note how the background color changes!). You may also choose to indent above/below to improve the appearance.

    • Add a border to the form. Set the width, color, and style.
    • Apply both a margin and padding to this text. The sum of both should be the same value of padding used in other elements (i.e., the inner text input should be aligned with the header and other text).

Lab 4: A Halloween movie website
Incorporating responsive design.

HTML Tasks

  1. Website Header: The name of the website.
  2. Image 1: Include an image that highlights the theme of the website.
  3. Subheading: Label the next section “Trending Movies”.
  4. Grids: Create a grid for four movie images.

    Start with the smallest size screen (mobile screen). Show a single movie on each line.
    For a medium size (tablet) screen, show two movies on a line.
    On a large (desktop) screen, show four movies on a line.

  5. Text: Add the name of each movie beneath the corresponding image within the grid. Make sure that the movie names remain positioned below each respective image at all sizes

CSS Tasks

    • Choose a background color to apply to the entire background
    • Choose a font other than the default font to apply to the entire page
    • Apply a background color to the heading that covers the full width of the page.
    • Choose a color for the heading text.
    • Set the position of the header appropriately, so that it acts as a navigation bar that remains at the top of the page, maintaining its position even as you scroll.
    • Optional margin/padding fix: Headers have default margin values. If you do not like the appearance of your top menu bar, change the margin/padding.
    • Set the width of the image to cover the full-width of the page.
    • Optional padding fix: Indent the heading by the same amount as the website header.
    • Set the width of all images to fit neatly within each grid.
    • Optional padding fix: You can use nested css properties to indent the movies by the same amount as the headers.
